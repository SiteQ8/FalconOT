# Support

## Getting Help

Thanks for using FalconOT! Here's how to get support.

### Documentation

- **README**: Start with the [README.md](README.md) for setup and usage
- **Contributing**: See [CONTRIBUTING.md](CONTRIBUTING.md) for development setup
- **Security**: See [SECURITY.md](SECURITY.md) for vulnerability reporting

### Community Support

- **GitHub Issues**: For bug reports and feature requests, use [Issues](https://github.com/SiteQ8/FalconOT/issues) with the appropriate template
- **GitHub Discussions**: For general questions, ideas, and community conversations

### Bug Reports

If something isn't working:

1. Check existing [issues](https://github.com/SiteQ8/FalconOT/issues) first
2. Use the **Bug Report** template when creating a new issue
3. Include your environment details (OS, browser, Python version)
4. Provide steps to reproduce the problem

### Feature Requests

Have an idea to improve FalconOT?

1. Check existing issues and discussions for similar requests
2. Use the **Feature Request** template
3. Describe your use case and how it benefits OT/ICS security

### Security Issues

**Do NOT open a public issue for security vulnerabilities.**

Follow the process in [SECURITY.md](SECURITY.md) to report security issues privately.

### Direct Contact

For sensitive matters or partnership inquiries:

- **Email**: site@hotmail.com
- **GitHub**: [@SiteQ8](https://github.com/SiteQ8)

### What to Expect

- **Bug reports**: Acknowledged within 48 hours
- **Feature requests**: Reviewed and triaged within one week
- **Security issues**: See response timelines in [SECURITY.md](SECURITY.md)

## Self-Help Checklist

Before reaching out, try these common solutions:

1. **Demo mode not loading?** — Ensure you're opening `docs/index.html` directly or via a local server
2. **API not connecting?** — Check that the API is running on `http://localhost:8000` and toggle "Use Live API" in the UI
3. **Docker issues?** — Run `docker compose down -v && docker compose up --build`
4. **Login not working?** — Demo credentials are: `FalconOT-Demo01` / `FalconOT`
